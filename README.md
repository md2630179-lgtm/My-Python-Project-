# My Python Project

This is a Python project repository containing various machine learning and Python scripts.

## Project Files:
* **`churn_project.py`**: Core Python script for Customer Churn prediction.
* **`dashboard.py`**: Script for generating the project dashboard.
* **`ml_data_processing_pipeline.py`**: Machine learning data processing pipeline.
* **`ml_evaluation_plots.py`**: Script for creating model evaluation plots and graphs.
* **`number_guessing_game.py`**: A simple number guessing game.
